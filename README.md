# Input Buffer Android

Android64 port/adaptation of [Lyoph's GMD-Buffer-Mod](https://github.com/Lyoph/GMD-Buffer-Mod), based on upstream v1.1.0.

## Status

This repository is an initial Android64 build port. The original mod was developed for Windows; Android compatibility and in-game behavior must be verified through GitHub Actions and on-device testing. A successful compile does not guarantee every hook behaves correctly on Android.

## Build on GitHub Actions (mobile-friendly)

1. Open the **Actions** tab.
2. Select **Build Input Buffer Android64**.
3. Tap **Run workflow** (or push a commit to start it automatically).
4. When it finishes, open the run and download the **Lyoph-Input-Buffer-Android64** artifact.
5. Extract the ZIP and install the `.geode` file with Geode.
